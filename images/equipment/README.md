# 機能訓練機器の写真フォルダ

このフォルダに、下の表の「ファイル名」で写真を入れると、ホームページに自動で表示されます。
写真が無い機器は「写真準備中」と表示されます。

| 機器 | ファイル名 |
| --- | --- |
| バイク | `bike.jpg` |
| ヒップアブダクション | `hip-abduction.jpg` |
| レッグプレス | `leg-press.jpg` |
| レッグエクステンション | `leg-extension.jpg` |
| チェストプレス | `chest-press.jpg` |
| フライ | `fly.jpg` |
| ローイング | `rowing.jpg` |
| 上肢滑車 | `pulley.jpg` |
| クランチ | `crunch.jpg` |
| ウォーターベッド | `water-bed.jpg` |
| ドクターメドマー | `medomer.jpg` |
| 低周波電気 | `low-frequency.jpg` |

- 写真は **横長（横4：縦3）** がきれいに収まります。
- ファイル名は **半角の小文字** で、上の表とまったく同じにしてください（`Bike.JPG` などは表示されません）。
- 1枚あたり **300KB以下**（横幅800px程度）にすると、ページの表示が速くなります。
